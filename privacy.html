Privacy Policy

Effective date: September 10, 2026

Fasto Browser Extension processes download and media information locally so the user can send a selected download to the Fasto desktop application. Fasto does not operate a remote analytics or data-collection server for the extension.

Information processed

To provide browser download integration, the extension may process the current page URL and title, selected link URLs, browser-created download URLs, detected media URLs, media type, quality and size, referrer/origin information, browser user-agent information, and limited non-sensitive request/response metadata.

This information is used only to detect downloadable content, display the Fasto download controls, and send a user-selected or browser-created download to the locally installed Fasto desktop application.

Information Fasto does not collect

The extension does not collect passwords, cookies, authorization headers, payment information, health information, personal communications, form entries, precise location, or keystrokes. It does not sell user data and does not use data for advertising, credit decisions, or purposes unrelated to download management.

Local processing and retention

Detected page and media information is held temporarily in browser memory and is cleared when it expires, the tab closes or navigates, or the browser restarts. Information sent through native messaging goes only to the Fasto desktop application installed on the same device. The desktop application may retain download URLs and download history locally so the user can manage and resume downloads.

Sharing and transfers

Fasto does not sell or transfer extension data to third parties. The desktop application connects to the website or file host identified by the user in order to perform the requested download; those websites remain subject to their own privacy policies.

Permissions

The extension uses browser permissions for context-menu downloads, native messaging, browser-download handoff, active-tab context, and HTTP/HTTPS request metadata needed to detect supported downloads and media. These permissions are used only for the extension's single purpose: integrating browser downloads with Fasto.

User choices

Users can stop all extension processing by disabling or removing the extension. They can remove locally retained download history through Fasto or uninstall the Fasto desktop application.

Security

Fasto limits native messaging to the registered Fasto extension and intentionally excludes cookies and authorization headers from captured request metadata. No method of software security is perfect, but Fasto is designed to minimize the information processed and keep it on the user's device.

Changes to this policy

This policy may be updated when Fasto's functionality or disclosure requirements change. The effective date above will be updated when a revised policy is published.
